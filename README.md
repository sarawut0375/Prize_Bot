# Price Bot — บอทสืบและเปรียบเทียบราคาสินค้า

เว็บแอปสำหรับใส่ข้อมูลสินค้าที่ต้องการติดตาม แล้วให้ระบบสืบราคาจากหลายแหล่ง
(Shopee, Lazada, Kaidee, Facebook Marketplace) มาเปรียบเทียบกันในหน้าเว็บ
พร้อมแจ้งเตือนทันทีผ่าน Telegram เมื่อราคาเปลี่ยนหรือถึงราคาเป้าหมาย

## ความสามารถ

- เพิ่มสินค้าที่ต้องการติดตาม พร้อมคำค้นหาและเลือกแหล่งที่จะสืบราคา
- ตั้งราคาเป้าหมาย (target price) และเลือกว่าจะแจ้งเตือนทุกครั้งที่ราคาเปลี่ยนหรือไม่
- ระบบสืบราคาอัตโนมัติตามรอบเวลาที่กำหนด (ตั้งค่าได้ใน `.env`) และกดรีเฟรชเองได้ทันที
- หน้าเว็บแสดงตารางเปรียบเทียบราคาล่าสุดจากทุกแหล่งของสินค้านั้น ๆ
- แจ้งเตือนผ่าน Telegram ทันทีเมื่อราคาต่ำสุดเปลี่ยนแปลง หรือถึงราคาเป้าหมาย
- เก็บประวัติราคาทุกครั้งที่สืบ ดูย้อนหลังได้ในหน้ารายละเอียดสินค้า
- แสดงสถานะการเชื่อมต่อของแต่ละแหล่ง (🟢 ออนไลน์ / 🔴 ออฟไลน์ / ✋ ใส่เอง) พร้อมจำนวนที่เจอล่าสุด ทั้งในหน้ารายการและหน้ารายละเอียดสินค้า

## การเชื่อมต่อแต่ละเว็บทำงานอย่างไร

บอทนี้ **ไม่ได้ใช้ API ทางการ** ของเว็บไหนเลย (ส่วนใหญ่ไม่มีให้ใช้แบบสาธารณะ) แต่ใช้วิธี
"ขอข้อมูลแบบเดียวกับที่หน้าเว็บขอ" ผ่านไลบรารี `requests` ในโค้ด Python ล้วน ๆ โดยเฉพาะ:

- **Kaidee** (`app/scrapers/kaidee.py`) — ยิง GET ไปที่หน้าค้นหา `kaidee.com/search?q=...`
  แล้วดึงข้อมูล JSON ที่ฝังอยู่ในหน้าเว็บ (`__NEXT_DATA__`) ซึ่งเป็นข้อมูลเดียวกับที่หน้าเว็บใช้แสดงผล
- **Shopee** (`app/scrapers/shopee.py`) — เรียก API ค้นหาสาธารณะของ Shopee เอง
  (`shopee.co.th/api/v4/search/search_items`) ซึ่งเป็น endpoint เดียวกับที่เบราว์เซอร์เรียกตอนคุณพิมพ์ค้นหาบนเว็บ
- **Lazada** (`app/scrapers/lazada.py`) — **ปิดการใช้งานอัตโนมัติ** (ดูด้านล่าง)
- **Facebook Marketplace** — **ไม่เชื่อมต่ออัตโนมัติ** เพราะ Facebook ไม่มี API สาธารณะสำหรับค้นหาสินค้า
  และต้องล็อกอินถึงจะเห็นรายการ การเขียนบอทไปสวมรอยเป็นผู้ใช้จริงเพื่อดึงข้อมูลขัดกับ Terms of Service
  ของ Facebook โดยตรง (เสี่ยงบัญชีโดนแบน) จึงตั้งใจไม่ทำส่วนนี้ ใช้การกรอกราคาด้วยมือแทน

เว็บพวกนี้มีระบบป้องกันบอท (anti-bot) และอาจเปลี่ยนโครงสร้างหน้าเว็บ/API เมื่อไหร่ก็ได้โดยไม่แจ้งล่วงหน้า
ถ้าสถานะในหน้าเว็บขึ้น 🔴 ออฟไลน์ ให้ดู error message (เมาส์ชี้ที่ป้ายสถานะ หรือดูหน้ารายละเอียดสินค้า)
ส่วนใหญ่จะเป็นเพราะถูกบล็อก IP หรือ selector/endpoint ที่ใช้ไม่ตรงกับเว็บแล้ว ต้องเข้าไปแก้โค้ดในไฟล์ scraper นั้น ๆ

## ⚠️ Lazada ปิดการสืบราคาอัตโนมัติ (ตรวจพบว่าโดนบล็อกจริง)

ตอนทดสอบจริง คำขอไปที่ Lazada ถูก redirect ไปที่หน้า
`lazada.co.th/catalog/_____tmd_____/punish?x5secdata=...` ซึ่งเป็น**หน้าลงโทษของระบบแอนตี้บอท
(TMD) ของเครือ Alibaba/Lazada** แปลว่าระบบของ Lazada ตรวจจับได้แล้วว่าทราฟฟิกนี้เป็นบอท

เพื่อความปลอดภัยของบัญชี/IP คุณ โปรเจกต์นี้**ไม่พยายามหลบเลี่ยงการตรวจจับนั้นต่อ** — การแก้ไขให้
"หลบ" ระบบที่จับได้แล้ว (เช่น แก้ captcha อัตโนมัติ) ถือเป็นการเลี่ยงระบบความปลอดภัยโดยตรง ไม่ใช่แค่
การสืบราคาทั่วไป และเสี่ยงให้ IP โดนบล็อกหนักขึ้นไปอีก **Lazada จึงถูกปิดการสืบอัตโนมัติไว้โดย default**
ใช้ฟอร์ม "เพิ่มราคาด้วยตนเอง" แทนเหมือน Facebook (ระบบยังเปรียบเทียบและแจ้งเตือนราคานี้ได้ตามปกติ)

ถ้าต้องการเปิดใช้ใหม่ด้วยความเสี่ยงของตัวเอง ดูวิธีได้ในคอมเมนต์ท้ายไฟล์ `app/scrapers/lazada.py`
(ไม่แนะนำ)

## ⚠️ ข้อจำกัดสำคัญเรื่องการสืบราคาแต่ละแหล่ง

| แหล่ง | สถานะ | หมายเหตุ |
|---|---|---|
| Kaidee | สืบอัตโนมัติ (best-effort) | ใช้ข้อมูลที่ฝังอยู่ในหน้าเว็บ อาจต้องแก้ selector ถ้าเว็บเปลี่ยนโครงสร้าง — ตอนนี้ดูเหมือนเว็บโหลดผลค้นหาด้วย JS ฝั่ง client ทำให้ยังดึงไม่ได้ |
| Shopee | สืบอัตโนมัติ (best-effort) | ใช้ API ค้นหาสาธารณะของ Shopee เอง อาจถูกบล็อก/จำกัดจาก IP ของเซิร์ฟเวอร์ (anti-bot) |
| Lazada | **ปิดอัตโนมัติ** — ตรวจพบว่าโดนระบบแอนตี้บอทบล็อกจริง (ดูหัวข้อด้านบน) | ใช้ฟอร์ม "เพิ่มราคาด้วยตนเอง" แทน |
| Facebook Marketplace | **ไม่มี API สาธารณะ และต้องล็อกอินเพื่อดูสินค้า** การสืบอัตโนมัติผ่าน Facebook ขัดกับ Terms of Service ของ Facebook จึงไม่ได้ทำให้ในโปรเจกต์นี้ | ใช้ฟอร์ม "เพิ่มราคาด้วยตนเอง" ในหน้ารายละเอียดสินค้าแทน ระบบจะเก็บและเปรียบเทียบราคานี้เหมือนแหล่งอื่น ๆ และยังแจ้งเตือนผ่าน Telegram ได้ปกติ |

ถ้า Shopee เริ่มบล็อก ให้ปรับ `SCRAPE_INTERVAL_MIN_MINUTES` / `SCRAPE_INTERVAL_MAX_MINUTES`
ใน `.env` ให้ห่างขึ้น (เช่น 20-60) หรือรันบอทจากเครื่อง/IP บ้านของคุณเองแทนเซิร์ฟเวอร์คลาวด์
ดูรายละเอียดเพิ่มเติมในคอมเมนต์ของไฟล์ `app/scrapers/shopee.py`

## ทำไมบางแหล่งขึ้น "🟢 ออนไลน์" แต่ "เจอ 0 รายการ"

สถานะ 🟢 ออนไลน์ แปลว่าเว็บนั้นตอบกลับมาสำเร็จ (ไม่ error, ไม่ถูกบล็อก) แต่โค้ดแกะข้อมูลจากคำตอบ
นั้นไม่เจอรายการสินค้าเลย ซึ่งต่างจาก 🔴 ออฟไลน์ (เชื่อมต่อไม่สำเร็จเลย) สาเหตุที่พบบ่อยที่สุดคือ
**เว็บนั้นโหลดผลการค้นหาด้วย JavaScript หลังจากหน้าเว็บโหลดเสร็จแล้ว** (ต่างจากตอนเปิดในเบราว์เซอร์จริง
ที่ JS รันให้อัตโนมัติ) ทำให้ request แบบธรรมดาที่บอทใช้เห็นแต่หน้าเปล่า ๆ หรือโครงสร้างข้อมูลเปลี่ยนไปจาก
ที่โค้ดคาดไว้

วิธีช่วยวินิจฉัย: รันบอทแล้วดู log ใน terminal (หน้าต่างที่รัน `python run.py` ค้างอยู่) ตอนที่สถานะขึ้น
0 รายการ จะมีบรรทัด `INFO price_bot.scrapers.xxx: ... found 0 items ... Top-level JSON keys: [...]`
หรือ `__NEXT_DATA__ present: False` ซึ่งบอกเบาะแสว่าควรแก้ตรงไหน ถ้าเจอข้อความแบบนี้ ก็อปปี้มาส่งให้ช่วยดูได้
(โค้ด scraper ที่เกี่ยวข้องอยู่ในโฟลเดอร์ `app/scrapers/`)

## การติดตั้งและรัน (Windows)

```powershell
# 1. สร้างและเปิดใช้ virtual environment
python -m venv venv
venv\Scripts\activate

# 2. ติดตั้งไลบรารี
pip install -r requirements.txt

# 3. ตั้งค่า .env
copy .env.example .env
# แก้ TELEGRAM_BOT_TOKEN และ TELEGRAM_CHAT_ID ในไฟล์ .env (ดูวิธีได้มาในไฟล์นั้น)

# 4. รันเว็บแอป
python run.py
```

เปิดเบราว์เซอร์ไปที่ `http://localhost:8000`

## การติดตั้งและรัน (macOS / Linux)

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python run.py
```

## ตั้งค่า Telegram Bot

1. เปิด Telegram คุยกับ `@BotFather` พิมพ์ `/newbot` แล้วทำตามขั้นตอน จะได้ token
2. ใส่ token ลงใน `.env` ที่ `TELEGRAM_BOT_TOKEN`
3. ส่งข้อความอะไรก็ได้ให้บอทของคุณ 1 ครั้งก่อน
4. เปิด `https://api.telegram.org/bot<TOKEN>/getUpdates` ในเบราว์เซอร์ จะเห็น
   `"chat":{"id": ...}` เอาเลขนั้นมาใส่ใน `.env` ที่ `TELEGRAM_CHAT_ID`

## โครงสร้างโปรเจกต์

```
app/
  main.py            FastAPI routes / หน้าเว็บ
  config.py          อ่านค่าตั้งค่าจาก .env
  database.py        เชื่อมต่อฐานข้อมูล SQLite
  models.py          โครงสร้างข้อมูล Product / PriceRecord
  price_checker.py   ตรรกะสืบราคา + ตัดสินใจแจ้งเตือน
  scheduler.py       รันงานตามรอบเวลา (APScheduler)
  telegram_notify.py ส่งข้อความแจ้งเตือนผ่าน Telegram
  scrapers/          โมดูลสืบราคาของแต่ละเว็บ (เพิ่ม/แก้ไขได้ที่นี่)
  templates/         หน้าเว็บ (Jinja2)
  static/            CSS
run.py               จุดเริ่มรันเว็บแอป
```

## แผนต่อยอด (ยังไม่ได้ทำ)

- เพิ่มกราฟราคาย้อนหลังในหน้ารายละเอียดสินค้า
- รองรับคำสั่งผ่าน Telegram (เช่น พิมพ์เพิ่มสินค้าจากแชทได้เลย)
- ใช้ Playwright/เบราว์เซอร์จริงสำหรับเว็บที่บล็อก request ธรรมดา (เพิ่ม robustness ให้ Shopee/Lazada)
- deploy ขึ้นเซิร์ฟเวอร์จริง (เช่น Railway, Render, VPS) ให้รันตลอดเวลา
