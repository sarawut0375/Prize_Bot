ปุ่มเก็บราคา (ส่วนขยายเบราว์เซอร์) แนะนำ

ปุ่มนี้อยู่บนแถบเครื่องมือของ Edge / Chrome เวลาดูสินค้าที่ไหนก็ได้ (Facebook, Shopee, Lazada, Kaidee หรือเว็บร้านอื่น) กดทีเดียว ระบบจะดึงชื่อ ลิงก์ รูป และราคา จากหน้าที่คุณเปิดอยู่มาให้ยืนยันแล้วบันทึก ส่วนขยายทำงานเฉพาะตอนคุณกดเท่านั้น และไม่เข้าเว็บไหนเอง

ติดตั้งครั้งเดียว

  1. เปิดหน้า edge://extensions (ถ้าใช้ Chrome: chrome://extensions) — พิมพ์ลงช่องที่อยู่เว็บแล้วกด Enter
  2. เปิดสวิตช์ โหมดนักพัฒนา (Developer mode) — Edge อยู่แถบซ้ายด้านล่าง, Chrome อยู่มุมขวาบน
  3. กด โหลดที่คลายการบีบอัด (Load unpacked) แล้วเลือกโฟลเดอร์นี้:
    {{ extension_path }}
  4. กดไอคอนจิ๊กซอว์ 🧩 บนแถบเครื่องมือ แล้วปักหมุด "Price Bot – เก็บราคา" ไว้ (จะเห็นไอคอน ฿)

วิธีใช้

  • • เปิดหน้าสินค้า → กดไอคอน ฿ หรือกด Alt+Shift+P
  • • ถ้าราคาไม่ขึ้นเอง (เช่น Facebook): ลากคลุมตัวเลขราคาบนหน้าเว็บ → คลิกขวา → "เก็บราคา ... เข้า Price Bot"
  • • ต้องเปิด python run.py ค้างไว้ระหว่างใช้งาน

Edge อาจแจ้งเตือนเรื่อง "ส่วนขยายในโหมดนักพัฒนา" ตอนเปิดเบราว์เซอร์ — เป็นปกติสำหรับส่วนขยายที่ติดตั้งเอง กดปิดการแจ้งเตือนได้ (อย่ากดปิดส่วนขยาย)

ทางเลือกสำรอง: ปุ่มบนแถบ Bookmark (ใช้ไม่ได้กับ Facebook)

Edge / Chrome รุ่นใหม่ไม่ยอมให้เว็บสาธารณะ (เช่น Facebook) เปิดหน้าบนเครื่องคุณเอง ปุ่ม Bookmark จึงขึ้น about:blank#blocked บนเว็บเหล่านั้น แต่อาจใช้ได้กับบางเว็บ

📌 เก็บราคา ← ลากไปวางที่แถบ Bookmark (Ctrl+Shift+B ถ้ามองไม่เห็นแถบ)
