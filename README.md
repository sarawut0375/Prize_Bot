# Price Bot — รวบรวมและเปรียบเทียบราคาสินค้า

เว็บแอปที่รันบนเครื่องคุณเอง ใช้รวบรวมราคาสินค้าที่คุณหาจาก Facebook Marketplace, Shopee, Lazada,
Kaidee (และเว็บอื่นๆ) มาสรุปไว้ในหน้าเดียว พร้อมแจ้งเตือนผ่าน Telegram เมื่อเจอราคาที่ใช่

## แนวคิด: คนกด ระบบจด

- **คุณ**เปิดหน้าค้นหาเองในเบราว์เซอร์ของคุณ (ล็อกอินด้วยบัญชีที่ตั้งไว้สำหรับงานนี้ได้ตามปกติ)
- เจอชิ้นที่สนใจ กดปุ่ม **📌 เก็บราคา** บนแถบ Bookmark ครั้งเดียว → ชื่อ ราคา ลิงก์ และรูป เข้าระบบทันที
- ระบบสรุปราคาต่ำสุดของแต่ละสินค้า และแจ้ง Telegram เมื่อถึงราคาเป้าหมาย / เจอราคาต่ำสุดใหม่ / ราคาเปลี่ยน
- **Shopee** ค้นหาอัตโนมัติได้ผ่าน **Shopee Affiliate Open API** ซึ่งเป็นช่องทางทางการ (ต้องมี key ของคุณเอง)

ระบบ**ไม่เก็บรหัสผ่าน ไม่ล็อกอินแทน และไม่เข้าเว็บเหล่านี้เอง** (ยกเว้น Shopee API ทางการ)
เพราะการให้โปรแกรมล็อกอินและกดแทนคนคือสิ่งที่ทำให้บัญชีโดนแบน — เมื่อคนกดเอง ก็คือการใช้งานปกติ

## หน้าเว็บ

| หน้า | ใช้ทำอะไร |
|---|---|
| **ผลลัพธ์** (`/`) | การ์ดสรุปแต่ละสินค้า: ราคาต่ำสุด, ราคาต่ำสุดแยกตามเว็บ, ปุ่มเปิดหน้าค้นหาของแต่ละเว็บ |
| **รายละเอียดสินค้า** (`/product/…`) | ทุกรายการที่เก็บไว้: รูป ชื่อ ราคา (และราคาก่อนหน้า) แหล่ง ผู้ขาย พื้นที่ สภาพ เวลา — กรองตามเว็บ / เรียงตามราคาได้ |
| **จัดการ** (`/manage`) | เพิ่ม/แก้สินค้าที่ต้องการหา, ติดตั้งปุ่มเก็บราคา, ลิงก์ค้นหาแต่ละเว็บ, Telegram, Shopee API key |

## ติดตั้งและรัน (Windows)

```powershell
cd "C:\Users\Boy\OneDrive\Project Prize_Bot"
python -m venv venv            # ครั้งแรกครั้งเดียว (ถ้ามีโฟลเดอร์ venv แล้วข้ามได้)
venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

เปิด **http://localhost:8000** แล้วเริ่มที่หน้า **จัดการ**:

1. เพิ่มสินค้าที่ต้องการหา (ชื่อ, คำค้นหา, ราคาเป้าหมาย)
2. ลากปุ่ม **📌 เก็บราคา** ไปไว้ที่แถบ Bookmark (`Ctrl+Shift+B` ถ้ามองไม่เห็นแถบ)
3. ใส่ Telegram Bot Token + Chat ID แล้วกด "ส่งข้อความทดสอบ"
4. (ถ้ามี) ใส่ Shopee Affiliate AppID + Secret แล้วกด "ทดสอบการเชื่อมต่อ"

ข้อควรรู้:
- ต้องเปิด `python run.py` ค้างไว้ระหว่างใช้งาน (ปุ่มเก็บราคาส่งข้อมูลมาที่โปรแกรมนี้)
- ถ้าราคาไม่ขึ้นเองตอนกดเก็บราคา (เช่น Facebook) ให้**ลากคลุมตัวเลขราคา**บนหน้าเว็บก่อนแล้วกดอีกครั้ง
- เก็บลิงก์เดิมซ้ำ = อัปเดตราคา (ระบบจำราคาก่อนหน้าไว้ให้)
- ข้อมูลทั้งหมด (รวม key ต่างๆ) อยู่ในไฟล์ `pricebot.db` บนเครื่องนี้ หน้าเว็บเปิดได้จากเครื่องนี้เท่านั้น

## Shopee Affiliate Open API

1. สมัคร Shopee Affiliate Program ที่ https://affiliate.shopee.co.th
2. ได้รับอนุมัติแล้ว ขอสิทธิ์ Open API ในหน้า affiliate → ได้ AppID และ Secret
3. ใส่ในหน้าจัดการ → "ทดสอบการเชื่อมต่อ" → เปิด "ค้นหาอัตโนมัติตามรอบเวลา" ได้

ส่วนนี้เขียนตามเอกสาร API ของ Shopee แต่ยังไม่ได้ทดสอบกับ key จริง ถ้าทดสอบแล้วขึ้น error
ให้ส่งข้อความ error มาเพื่อปรับแก้
